# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential or
customer-data problem. Use this repository's private vulnerability reporting
feature. If it is unavailable, contact the repository owner privately through
GitHub and include enough detail to reproduce the issue safely.

Please do not include real customer data, production access tokens or secrets
in a report.

## Supported versions

Only the current `main` branch is supported while Shopoll is in dogfood.
